🔄 FLUXO DETALHADO
═══════════════════════════════════════════════════════════════════════════════

[1] Câmera captura imagem
    └─ NormalCamera.capture()
    └─ JPEG comprimido em memória

[2] SmolVLM2 analisa (Tentativa primária)
    ├─ Salva em temp file
    ├─ model = SmolVLM2Optimized()
    ├─ await model.initialize()  [2-3s primeira vez]
    ├─ await model.analyze_image(path)  [10-15s]
    └─ Resultado: {"success": bool, "description": str}

[3] Se SmolVLM2 falhar, usa LLaVA (Fallback)
    ├─ camera = get_camera_instance()  [VLCamera + Ollama]
    ├─ camera.analyze(question, context)  [60-90s]
    └─ Resultado: JSON com descrição

[4] Enriquecimento de contexto
    ├─ Extrai descrição do resultado
    ├─ Monta prompt com imagem + pergunta
    └─ Retorna ao MCP para LLM processar

[5] LLM processa e responde
    ├─ Lê contexto enriquecido
    ├─ Gera resposta
    └─ Retorna ao cliente
