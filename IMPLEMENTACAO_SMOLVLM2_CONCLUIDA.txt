🔄 FLUXO DE EXECUÇÃO
═══════════════════════════════════════════════════════════════════════════

1. Usuário: python main.py
   ↓
2. Sistema: Carrega configuração
   ↓
3. Camera tool: Recebe chamada take_photo()
   ↓
4. take_photo(): Verifica se SmolVLM2 está disponível
   ├─ SIM → Tenta usar SmolVLM2
   │   ├─ Sucesso? → Retorna descrição (10-15s) ✅

   └─ NÃO → Vai direto para fallback
   ↓
5. Fallback: Usa LLaVA + Ollama
   ├─ Sucesso? → Retorna descrição (60-90s)
   └─ Falha? → Retorna erro
   ↓
6. Sistema: Injeta descrição no contexto do usuário
   ↓
7. LLM: Processa e responde
